Sub-domain membership is derived from each dataset's own title and tags. A dataset sits in exactly one sub-domain for counting (the hierarchy view), but may match several — those additional matches are what the relationship view draws. Publisher descriptions are excluded from the relationship pass, because several exchanges reuse one description across an entire upload batch. Other spatial layers is a catch-all for records whose only signal is that they are spatial, so it links widely by construction.
